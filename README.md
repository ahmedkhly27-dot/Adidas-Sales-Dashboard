# 👟 Adidas Sales Dashboard

An interactive Power BI dashboard built using the Adidas US Sales dataset to analyze sales performance, profitability, retailers, products, and regional trends.

---

## 🚀 Project Overview

This dashboard provides insights into:

- Total Sales
- Total Profit
- Total Units Sold
- Sales by Product
- Sales by Sales Method
- Top States by Sales
- Monthly Sales Trend
- Retailer Performance
- Sales vs Units Sold

---

## 🛠 Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

---
